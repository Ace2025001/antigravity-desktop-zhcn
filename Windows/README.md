# Windows 平台一键脚本入口

本目录归档了适用于 **Windows x64** 平台的全部批处理启动器（`.bat`），与项目根目录下的跨平台核心汉化引擎（`src/`）及共享词典（`config/dom-translations.json`）配合使用。

## 常用入口说明

| 脚本名称 | 作用说明 |
| --- | --- |
| `一键汉化.bat` | 引导式安装简体中文补丁（若未登记指纹会自动回退至自适应汉化） |
| `启动 Antigravity（自动汉化）.bat` | 动态自适应汉化并启动客户端（推荐客户端更新后使用） |
| `生成桌面快捷方式.bat` | 在桌面创建自动汉化启动快捷方式 |
| `一键检查兼容性.bat` | 检查本机客户端版本、ASAR 指纹与兼容状态 |
| `一键恢复英文.bat` | 从原始备份恢复官方英文原版客户端 |
| `自动跟进更新.bat` | 手动触发自适应跟进客户端更新流程 |
| `生成汉化预览.bat` | 仅在 `.runtime/` 下生成汉化产物供预览，不修改客户端文件 |
| `清理缓存.bat` | 安全清理汉化工具生成的临时缓存与过期备份 |
| `完全卸载.bat` | 恢复官方原版并彻底清除所有本地汉化产物、备份与配置 |
