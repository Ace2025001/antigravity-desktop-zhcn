Antigravity 汉化包

Windows：打开 win启动，双击启动中文。
Mac：打开 mac启动，双击启动中文。
想恢复英文：先保存工作，双击恢复英文。

已汉化且资源有效时直接打开；语言包或客户端更新后尝试重新应用。首次运行自动查找客户端，找到多个时选择；找不到时弹出文件选择窗口。选择的位置会记住，失效后重新查找。
需要修改而客户端仍在运行时，提示保存并退出：60秒内手动退出会自动继续；按Y立即强制关闭，按N不强制、一直等你手动退出；60秒无操作时先请求正常退出，仍未退出则强制关闭。无法可靠判断用户是否正在工作，因此不会把低CPU占用当作空闲。

成功启动后，在桌面和本系统启动目录创建 Antigravity自动汉化 快捷方式。不存在才创建，目标变化才更新，不重复写入，不覆盖用户同名文件。移动整个包后，从新位置运行一次启动中文即可更新桌面快捷方式。

目录分工：
语言包：共用词库、核心程序及依赖，只存一份。
win启动/配套程序：Windows专用运行环境。
mac启动/配套程序：Mac专用运行环境。
依赖已内置，不需要联网下载运行环境。保留整个目录结构，不要只复制快捷方式。

更新翻译通常只替换语言包里的JSON词库。整个语言包的替换应使用与当前入口兼容的正式版本。官方客户端结构变化仍可能需要适配，不能保证所有版本自动成功。
Windows x64 与 Mac Apple芯片；Intel Mac尚未验证。Mac系统对话框、签名、主窗口与桌面快捷入口仍需真实Mac客户端验收。工具不修改代理、节点或TUN。
