Antigravity 汉化包

Windows：打开 win启动，双击启动中文。
Mac：打开 mac启动，双击启动中文。
想卸载汉化：先保存工作，双击卸载汉化。

已汉化且资源有效时直接打开；语言包或客户端更新后尝试重新应用。首次运行自动查找客户端，找到多个时选择；找不到时弹出文件选择窗口。选择的位置会记住，失效后重新查找。
需要修改而客户端仍在运行时，提示保存并退出：60秒内手动退出会自动继续；按 1 立即强制关闭，按 2 不强制、一直等你手动退出；60秒无操作时先请求正常退出，仍未退出则强制关闭。无法可靠判断用户是否正在工作，因此不会把低CPU占用当作空闲。

首次运行会问几项设置，直接回车即用推荐值，之后可双击“汉化设置”修改：
- 客户端更新后怎么处理（Windows）：自动汉化（推荐）/先问我/不处理。在客户端里点“重启以更新”后自动重新汉化或弹窗询问，不常驻后台；卸载汉化或卸载时自动移除。
- 汉化包自动更新：自动更新（推荐）/先问我/关闭。启动或退出客户端时按设置检查 GitHub 最新版本并校验 SHA-256。
- 标题自动翻译：开启（推荐）/关闭。软件界面全部采用人工词库，仅将 Antigravity 自动生成的纯英文对话标题译为中文显示；对话内容、代码、终端输出、文件和用户输入不会发送，手动重命名的标题保持英文。关闭后标题也不联网。
对话标题默认只在界面上显示中文，不修改你的对话记录。

目录分工：
语言包：共用词库、核心程序及依赖，只存一份。
win启动/配套程序：Windows专用运行环境。
mac启动/配套程序：Mac专用运行环境。
依赖已内置，不需要联网下载运行环境；汉化本身不需要联网。保留整个目录结构，不要只复制快捷方式。

更新翻译通常只替换语言包里的JSON词库。整个语言包的替换应使用与当前入口兼容的正式版本。官方客户端结构变化仍可能需要适配，不能保证所有版本自动成功。
Windows x64 与 Mac Apple芯片；Intel Mac尚未验证。Mac系统对话框、签名、主窗口与桌面快捷入口仍需真实Mac客户端验收。工具不修改代理、节点或TUN。
