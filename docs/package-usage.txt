Antigravity 汉化包

Windows：打开 win启动，双击“启动中文”。
Mac：打开 mac启动，双击“启动中文”。
想卸载汉化：先保存工作，双击“卸载汉化”。
想改设置、查看当前版本或手动检查更新：双击“汉化设置”。

首次运行会自动查找客户端，找到多个时让你选择，找不到时弹出文件选择窗口；选择的位置会记住。
需要修改而客户端正在运行时，会提示保存并退出：60 秒内手动退出会自动继续；按 1 立即关闭，按 2 一直等你手动退出；60 秒无操作时先请求正常退出，仍未退出则强制关闭。
成功启动后会在桌面创建“Antigravity自动汉化”快捷方式；移动整个汉化包后，从新位置运行一次“启动中文”即可更新快捷方式。

首次运行会问几项设置，直接回车即用推荐值，之后可双击“汉化设置”修改：
- 客户端更新后怎么处理（Windows）：自动汉化（推荐）/ 先问我 / 不处理。
- 汉化包自动更新：自动更新（推荐）/ 先问我 / 关闭。打开或退出客户端时检查 GitHub 最新版本并校验 SHA-256。
- 界面联网补充翻译：开启（推荐）/ 关闭。汉化包还没收录的界面文字先临时显示中文，收录人工译文后自动替换。
- 标题自动翻译：开启（推荐）/ 关闭。Antigravity 自动生成的英文对话标题在界面上显示为中文，对话记录保持原样。
联网时只发送界面文字和对话标题；对话内容、代码、终端输出、文件和你输入的内容都留在本机。

目录分工：
语言包：词库和核心程序。
win启动/配套程序：Windows 运行环境。
mac启动/配套程序：Mac 运行环境。
请保留整个目录结构。

支持 Windows x64 与 Apple 芯片 Mac（Intel Mac 尚未验证）。
