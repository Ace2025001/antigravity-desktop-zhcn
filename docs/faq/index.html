Antigravity 汉化常见问题

关于 Antigravity Desktop 中文汉化包的安装、更新、卸载汉化和兼容范围，这里集中回答最常见的问题。

Google Antigravity（反重力）桌面客户端怎么设置成中文？

Antigravity Desktop 客户端界面为英文时，可以使用本汉化包：下载完整汉化包，完整解压后打开 win启动（Windows）或 mac启动（Mac），双击“启动中文”，按提示操作即可。详细步骤见 Windows 教程和 Mac 教程。

Antigravity 汉化包下载哪个文件？

普通用户只下载“Antigravity-完整汉化包-Windows+Mac.zip”，下载后文件名显示为 Antigravity-Windows+Mac.zip，两者是同一个文件。它同时包含 Windows 和 Mac 入口。只需要这一个文件，Source code 和绿色 Code 按钮里是给开发者用的源码。

支持哪些系统版本？

支持 Windows x64 和 Apple 芯片 Mac 上的 Antigravity Desktop 独立桌面客户端，Windows 已在 2.32.2、2.33.0、2.34.0、2.35.1 上实测。Intel Mac 尚未验证。每个客户端版本都要通过结构和资源检查，未登记的新版本会读取当前界面动态适配，但不承诺兼容所有版本。

适用对象是哪款软件？

本汉化包只适用于 Antigravity Desktop 独立桌面客户端。

需要安装 Node.js 或联网吗？

不需要安装 Node.js。完整汉化包内置 Windows 和 Mac 两端的运行环境与依赖，本地汉化本身不需要联网。“汉化包自动更新”“界面联网补充翻译”和“标题自动翻译”可在首次运行时选择，之后随时在“汉化设置”里开关。

Antigravity 更新后变回英文、汉化失效了怎么办？

Windows 上首次运行选了“自动汉化”（推荐）时，后台会自动检查并重新汉化，通常不需要任何操作。也可以双击启动目录里的“启动中文”。工具会检查汉化是否仍然有效，客户端资源变化时尝试重新应用中文；结构检查不通过时停下并提示你。若已启用“汉化包自动更新”，客户端启动时也会自动检查汉化包新版本。

能恢复官方原版吗？

先保存工作并退出客户端，再运行对应系统启动目录里的“卸载汉化”。Windows 会还原原版文件；Mac 会启动未修改的官方原版。确认恢复成功前，请保留原版备份和汉化工具。

汉化会改动哪些内容？

Windows 会在备份原版后替换客户端界面资源；Mac 保留官方原版，另外在个人应用目录创建一个本地签名的中文副本。对话标题只在界面上显示中文，对话记录保持原样。

运行时客户端开着会怎样？

已汉化且检查通过时直接显示主窗口。需要修改文件而客户端仍在运行时，会提示保存并退出：60 秒内手动退出会被自动识别并继续；按 1 立即强制关闭，按 2 不强制、一直等你手动退出；60 秒无操作时先请求正常退出，仍未退出则强制关闭。开启了“后台运行”时，关闭窗口不会退出程序，请从托盘图标选择 Quit。

Mac 出现安全提示或打不开怎么办？

按系统提示处理即可，Gatekeeper 和 SIP 保持开启。从源码下载的脚本可能丢失执行权限，正式完整包已处理好权限。首次安装需要先打开官方原版，看到首页后按 ⌘Q 正常退出，再回到窗口按回车。

Mac 上中文版和原版能同时开吗？

一次只开一个。两者共用同一份用户资料，轮流使用最稳妥。

只想更新翻译，要重新下载完整包吗？

已有新版完整包时，到发布页下载“仅更新语言包-不能单独使用.zip”，替换原目录里的“语言包”文件夹，再运行一次“启动中文”。首次使用或文件不完整时，请下载完整包。

还看到英文没翻译怎么办？

先确认使用的是最新版本。仍有遗漏时，请在 问题反馈 里选择“漏翻 / 翻译优化建议”，附上英文原文、截图和所在界面，截图前请遮盖邮箱等隐私信息。

客户端更新后会自动汉化吗？

会。Windows 上首次运行时可以选择：自动汉化（推荐）、先问我、不处理。在客户端里点“重启以更新”后，汉化包会等新版本装好，自动关闭重启出来的英文窗口、重新汉化并打开中文版，过程中有进度窗口；先问我模式会在更新完成时弹窗询问。只在客户端启动或退出时运行。

联网补充翻译和标题自动翻译是什么？会发送我的对话吗？

界面优先使用 1.7 万多条人工整理的译文。Antigravity 更新后出现汉化包还没收录的按钮、菜单和提示时，开启“界面联网补充翻译”会通过谷歌翻译临时显示成中文，等汉化包收录人工译文后自动替换。由于 Antigravity 自动生成的对话标题默认为英文，开启“标题自动翻译”后会将纯英文对话标题译为中文显示（默认不改写对话记录）。两项可以在“汉化设置”里分别关闭。对话内容、代码、终端输出、本地项目文件夹、文件名、链接、路径、账号信息、你自己的技能和规则说明，以及你在对话中输入的内容都留在本机。如果想保留纯英文标题，亲手重命名会自动记住并保留原名，也可以在“汉化设置”中关闭此开关。“汉化包自动更新”读取 GitHub 发布页上的版本信息并下载安装包，也可以在“汉化设置”里关闭。

汉化包能自动更新吗？怎么修改这些设置？

可以。无论从桌面图标、任务栏、程序坞还是“启动中文”打开 Antigravity，都会按“汉化包自动更新”设置（自动更新 / 先问我 / 关闭）检查 GitHub 最新版本并校验 SHA-256。双击启动目录里的“汉化设置”（Windows 为 汉化设置.bat，Mac 为 汉化设置.command），即可修改以上全部选项。

能让 AI 助手帮我自动安装吗？

可以。把仓库地址发给豆包、DeepSeek、WorkBuddy、Claude Code、Codex、Cursor 等 AI 助手，让它按 AI 助手安装指南 操作。指南写明了下载地址、SHA-256 校验、各平台命令、结果判断和恢复方法。
