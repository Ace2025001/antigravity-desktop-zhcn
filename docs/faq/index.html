Antigravity 汉化常见问题

关于 Antigravity Desktop 中文汉化包的安装、更新、恢复英文和兼容范围，这里集中回答最常见的问题。

Antigravity 怎么设置成中文？

Antigravity Desktop 客户端界面为英文时，可以使用本汉化包：下载完整汉化包，完整解压后打开 win启动（Windows）或 mac启动（Mac），双击“启动中文”，按提示操作即可。详细步骤见 Windows 教程和 Mac 教程。

下载哪个文件？

普通用户只下载“Antigravity-完整汉化包-Windows+Mac.zip”，下载后文件名显示为 Antigravity-Windows+Mac.zip，两者是同一个文件。它同时包含 Windows 和 Mac 入口。不要下载 Source code 或绿色 Code 按钮里的源码。

支持哪些系统和客户端版本？

支持 Windows x64 和 Apple 芯片 Mac 上的 Antigravity Desktop 独立桌面客户端，已在 2.29.0 上实测。Intel Mac 尚未验证。每个客户端版本都要通过结构和资源检查，未登记的新版本会读取当前界面动态适配，但不承诺兼容所有版本。

能用于 Antigravity IDE 扩展吗？

不能。本汉化包只适用于 Antigravity Desktop 独立桌面客户端，不是 Antigravity IDE 扩展的语言包。

需要安装 Node.js 或联网吗？

不需要。完整汉化包内置 Windows 和 Mac 两端的运行环境与依赖，解压即可离线运行。

客户端更新后汉化失效了怎么办？

双击桌面上的“Antigravity自动汉化”或启动目录里的“启动中文”。工具会检查汉化是否仍然有效，客户端资源变化时尝试重新应用中文；结构检查不通过时会停止，不会强行修改。它不会自动从网上下载新词库，词库更新请到发布页下载。

怎么恢复英文？

先保存工作并退出客户端，再运行对应系统启动目录里的“恢复英文”。Windows 会还原原版文件；Mac 会启动未修改的官方原版。确认恢复成功前，请保留原版备份和汉化工具。

汉化会修改代理、网络或账号设置吗？

不会。工具不修改系统代理、节点或 TUN，也不修改账号与模型配置。Windows 会在备份后替换客户端界面资源；Mac 保留官方原版，另外在个人应用目录创建一个本地签名的中文副本。

运行时客户端开着会怎样？

已汉化且检查通过时直接显示主窗口。需要修改文件而客户端仍在运行时，会提示保存并退出：60 秒内手动退出会被自动识别并继续；按 Y 立即强制关闭，按 N 不强制、一直等你手动退出；60 秒无操作时先请求正常退出，仍未退出则强制关闭。开启了“后台运行”时，关闭窗口不会退出程序，请从托盘图标选择 Quit。

Mac 出现安全提示或打不开怎么办？

按系统提示处理即可，不要关闭 Gatekeeper 或 SIP。从源码下载的脚本可能丢失执行权限，正式完整包已处理好权限。首次安装需要先打开官方原版，看到首页后按 ⌘Q 正常退出，再回到窗口按回车。

Mac 上中文版和原版能同时开吗？

不要同时运行。两者共用同一份用户资料，同时打开可能互相影响。

只想更新翻译，要重新下载完整包吗？

已有新版完整包时，到发布页下载“仅更新语言包-不能单独使用.zip”，替换原目录里的“语言包”文件夹，再运行一次“启动中文”。首次使用、从 v2.2.0 及更早版本升级，或文件已删除时，请下载完整包。

还看到英文没翻译怎么办？

先确认使用的是最新版本。仍有遗漏时，请在 问题反馈 里选择“漏翻 / 翻译优化建议”，附上英文原文、截图和所在界面，截图前请遮盖邮箱等隐私信息。

能让 AI 助手帮我自动安装吗？

可以。把仓库地址发给 Claude Code、Codex、Cursor 等 AI 助手，让它按 AI 助手安装指南 操作。指南写明了下载地址、SHA-256 校验、各平台命令、结果判断和恢复方法。
