Antigravity Windows 汉化教程

完整包自带运行环境，无需安装 Node.js。先确认安装的是 Antigravity Desktop 独立桌面客户端。

安装中文

  1. 下载 Windows + Mac 完整包，右键“全部解压缩”。
  2. 打开 antigravity汉化包 → win启动 → 启动中文.bat。
  3. 工具会寻找已安装客户端；未找到或存在多个安装时，按弹窗选择正确的 Antigravity.exe。
  4. 按中文提示完成处理。成功后客户端启动，并在桌面和 win启动 文件夹创建“Antigravity自动汉化”。

C 盘、D 盘或自定义位置怎么办？

自动识别会参考安装信息及常见位置；找不到时可以手动选择。选择会被记住，下次位置仍有效时不必重复扫描。不要把其他同名软件或 IDE 选为桌面客户端。

客户端开着时会发生什么？

已经汉化且检查通过时直接显示主窗口。需要修改文件时，会提示保存工作，并逐秒等待 60 秒，再请求正常退出。不会强制终止；未保存提示阻止退出时会停止操作。

客户端更新后怎么处理？

双击“Antigravity自动汉化”或“启动中文”。汉化有效时直接打开，资源变化时尝试重新汉化。新版本无法通过检查时，请查看发布页与问题反馈，不要反复覆盖客户端文件。

恢复英文与卸载工具

先保存工作，运行 win启动 中的“恢复英文.bat”。确认恢复成功后再删除汉化包和自动汉化快捷方式，保留客户端与个人数据。

常见故障

如果 ZIP 显示为空，请下载 v2.3.1 或更新版本。如果双击无反应，先确认已完整解压且保留“语言包”和“配套程序”；检查错误提示，不要关闭系统安全防护。反馈时附上客户端版本、Windows 版本和脱敏后的错误信息。
