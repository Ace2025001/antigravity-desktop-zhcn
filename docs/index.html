Antigravity 中文汉化包

让 Google Antigravity（反重力）Desktop 桌面客户端显示简体中文。Windows 和 Apple 芯片 Mac 通用，解压即用，在客户端里点更新后自动跟着重新汉化，随时可以恢复英文。

下载完整汉化包 · Windows + Mac

三步开始使用

  1. 下载后右键“全部解压缩”。
  2. Windows 打开 win启动，Mac 打开 mac启动。
  3. 双击“启动中文”，按提示完成。

想换回英文，双击“恢复英文”；想改设置，双击“汉化设置”。

主要特点

  • 解压即用：内置运行环境，自动找到客户端。
  • 更新后自动汉化：在客户端里点“重启以更新”后，自动跟着重新汉化，也可以设为先询问。
  • 翻译全面：1.6 万条人工整理的译文，覆盖菜单、托盘、设置、智能体（Agent）执行过程、运行命令、MCP 工具调用、插件市场、模型配额和快捷键提示。
  • 联网补充翻译：补齐新版本里还没收录的英文，可随时关闭；不发送对话内容、代码和文件。
  • 安全可恢复：不修改对话记录，一键恢复英文。

常见问题

客户端更新后还要重新汉化吗？

不用。在客户端里点“重启以更新”后，汉化包会等新版本装好，自动重新汉化并打开中文版。Mac 用桌面上的“Antigravity自动汉化”打开即可。

支持哪些系统？

Windows x64 和 Apple 芯片 Mac，Intel Mac 未验证。只适用于 Antigravity Desktop 桌面客户端，不是 IDE 扩展。

能让 AI 助手帮我安装吗？

可以。把仓库地址发给 Claude Code、Codex、DeepSeek 等 AI 助手，让它按 AI 助手安装指南 操作。
