Antigravity 中文汉化包

让 Antigravity Desktop 桌面客户端显示简体中文。Windows 与 Apple 芯片 Mac 共用一份语言包，下载完整包、解压后按提示运行。

下载哪个文件？

普通用户选择「Antigravity-完整汉化包-Windows+Mac.zip」。浏览器下载的文件名可能显示为 Antigravity-Windows+Mac.zip，两者是同一个完整包。不要下载 Code 或 Source code。

三步开始使用

  1. 下载完整包，右键选择“全部解压缩”，不要在 ZIP 内直接运行。
  2. Windows 打开 win启动，Mac 打开 mac启动，双击“启动中文”。
  3. 根据提示选择客户端并完成处理；已汉化且检查通过时直接启动。

它能做什么？

自动识别客户端位置，找不到时手动选择；检测汉化是否仍然有效；成功启动后创建“Antigravity自动汉化”快捷方式；需要时通过“恢复英文”撤销修改。安装包内置运行所需文件，汉化工具可离线运行。

常见问题

客户端更新后怎么重新汉化？

运行“启动中文”或“Antigravity自动汉化”。工具检查资源变化后尝试适配；结构检查不通过时会停止。自动汉化不代表自动从网上下载新词库。

支持所有型号和版本吗？

不保证。完整包内置 Windows x64 与 Mac arm64 运行环境；Intel Mac 未验证。Mac 合并后的完整流程仍待真实客户端实机复验。每个客户端版本都需通过资源与结构检查。

只更新语言包需要重新下载完整包吗？

已有新版完整包时，可在发布页下载“仅更新语言包-不能单独使用.zip”，替换语言包目录。从 v2.2.0 或更早版本升级、首次使用或文件已删除时，请下载完整包。

如何恢复英文？

保存工作，打开对应系统的启动目录，运行“恢复英文”。请在恢复成功前保留原版备份和汉化工具。
