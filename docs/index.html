Antigravity 中文汉化包

让 Google Antigravity（反重力）Desktop 桌面客户端显示简体中文。Windows 和 Apple 芯片 Mac 通用，解压即用，在客户端里点更新后自动跟着重新汉化，随时可以卸载汉化、回到官方原版。

汉化效果与覆盖范围

主要特点

  • 解压即用：内置运行环境，自动找到客户端。
  • 自动更新汉化包：启动或退出客户端时按设置自动检查新版本汉化包，校验 SHA-256 后自动升级或弹窗提醒。
  • 更新后自动汉化：在客户端里点“重启以更新”后，自动跟着重新汉化，也可以设为询问。
  • 全面中文翻译：1.7 万条人工校对译文，覆盖菜单、托盘、设置、智能体（Agent）执行过程、Swarm 侧面板、运行命令、MCP 工具调用、插件市场、模型配额和快捷键提示；支持界面联网补充新文字与纯英文对话标题自动翻译。
  • 安全可恢复：对话记录原样保留，一键卸载汉化；Mac 保留官方原版，另建中文副本。

三步开始使用

  1. 下载后右键“全部解压缩”。
  2. Windows 打开 win启动，Mac 打开 mac启动。
  3. 双击“启动中文”，按提示完成。

想换回英文，双击“卸载汉化”；想改设置、查版本或检查更新，直接在客户端左上角 Antigravity 菜单点“汉化中心”。

首次使用的设置

第一次运行“启动中文”时会询问推荐设置，直接回车就是推荐值，以后随时可以在客户端左上角 Antigravity 菜单（Mac 在系统顶部菜单栏）点“汉化中心”修改。

  • 客户端更新后怎么处理（Windows）：自动汉化（推荐）/ 询问 / 不处理。选“自动汉化”时，在客户端里点“重启以更新”后约 40 秒自动变回中文；选“询问”会弹窗确认。汉化包只在客户端启动或退出时运行。
  • 汉化包自动更新：自动更新（推荐）/ 询问 / 关闭。无论以何种方式打开 Antigravity，都会按设置检查新版本并校验 SHA-256，新版本自动送到。
  • 界面联网补充翻译：开启（推荐）/ 关闭。界面优先用人工词库；客户端更新后出现汉化包还没收录的界面文字时，经谷歌翻译临时显示中文，收录人工译文后自动替换。只发送这些界面文字，对话内容、代码、终端输出、文件、账号信息和你输入的内容都留在本机。
  • 标题自动翻译：开启（推荐）/ 关闭。仅将 Antigravity 自动生成的纯英文对话标题译为中文；已排除对话内容、代码、终端输出、本地文件夹与路径。亲手重命名后会自动保留英文原名。

支持范围

  • Windows x64：已在 Antigravity Desktop 2.32.2、2.33.0、2.34.0、2.35.1、2.35.2 实测，支持更新后自动汉化。
  • Apple 芯片 Mac：保留官方原版，另建本地签名的中文副本；Intel Mac 未验证。
  • 适用对象：Antigravity Desktop 独立桌面客户端。
  • 每次汉化前检查客户端文件结构，新版本先尝试自动适配，对不上就停下并提示。

常见问题

Antigravity 更新后变回英文怎么办？

汉化包默认会自动处理。在客户端里点“重启以更新”后，工具会等新版本装好，自动重新汉化并打开中文版；若仍为英文，双击“启动中文”即可恢复中文。Mac 中文版用桌面上的“Antigravity自动汉化”打开即可。

能恢复官方原版吗？

能。保存工作后双击“卸载汉化”，客户端还原成官方英文原版，对话记录完整保留。

反重力汉化包下载完整包、语言更新包还是 Source code？

第一次使用只下载完整包（Antigravity-Windows+Mac.zip）。语言更新包只给已装过完整包的用户更新词条；Source code 是开发源码，不能直接使用。

支持哪些系统版本？

支持 Windows x64（已在 Antigravity Desktop 2.32.2 至 2.35.2 实测）和 Apple 芯片 Mac，Intel Mac 未验证。只适用于 Google Antigravity Desktop 独立桌面客户端。

能让 AI 助手帮我安装吗？

可以。把仓库地址发给豆包、DeepSeek、WorkBuddy、Claude Code、Codex 等 AI 助手，让它按 AI 助手安装指南 操作。
