Antigravity 中文汉化包

让 Google Antigravity（反重力）Desktop 桌面客户端显示简体中文。Windows 和 Apple 芯片 Mac 通用，解压即用，在客户端里点更新后自动跟着重新汉化，随时可以恢复英文。

下载完整汉化包 · Windows + Mac

三步开始使用

  1. 下载后右键“全部解压缩”。
  2. Windows 打开 win启动，Mac 打开 mac启动。
  3. 双击“启动中文”，按提示完成。

想换回英文，双击“恢复英文”；想改设置，双击“汉化设置”。

首次使用的两个设置

第一次运行“启动中文”时会问两个问题，直接回车就是推荐值，以后可双击“汉化设置”修改。

  • 客户端更新后怎么处理（Windows）：自动汉化（推荐）/ 先问我 / 不处理。选“自动汉化”时，在客户端里点“重启以更新”后约 40 秒自动变回中文；选“先问我”会弹窗询问。汉化包没有计划任务，也不常驻后台。
  • 联网补充翻译：开启（推荐）/ 关闭。优点是客户端更新后能实时补齐界面上还没收录的英文与对话标题；缺点是遇到被代码拆成多段的句子时，偶尔可能出现生硬机翻或局部中英混杂，可在“汉化设置”里随时关闭。对话内容、代码、终端输出、文件名、链接、路径和你输入的内容都不会发送。

主要特点

  • 解压即用：内置运行环境，自动找到客户端。
  • 更新后自动汉化：在客户端里点“重启以更新”后，自动跟着重新汉化，也可以设为先询问。
  • 翻译全面：1.6 万条人工整理的译文，覆盖菜单、托盘、设置、智能体（Agent）执行过程、运行命令、MCP 工具调用、插件市场、模型配额和快捷键提示。
  • 联网补充翻译：补齐新版本里还没收录的英文，可随时关闭；不发送对话内容、代码和文件。
  • 安全可恢复：不修改对话记录，一键恢复英文；Mac 保留官方原版，另建中文副本。
  • 不碰你的环境：不修改代理、节点和系统设置，不安装后台服务。

汉化效果

支持范围

  • Windows x64：已在 Antigravity Desktop 2.32.2、2.33.0、2.34.0、2.35.1 实测，支持更新后自动汉化。
  • Apple 芯片 Mac：保留官方原版，另建本地签名的中文副本；Intel Mac 未验证。
  • 只适用于 Antigravity Desktop 桌面客户端，不是 Antigravity IDE 扩展。
  • 每次汉化前检查客户端文件结构，新版本先尝试自动适配，对不上就停下并提示。

常见问题

Antigravity 更新后变回英文怎么办？

汉化包默认会自动处理。在客户端里点“重启以更新”后，工具会等新版本装好，自动重新汉化并打开中文版；若仍为英文，双击“启动中文”即可恢复中文。Mac 中文版用桌面上的“Antigravity自动汉化”打开即可。

能恢复英文吗？

能。保存工作后双击“恢复英文”，客户端还原成官方英文原版，对话记录不受影响。

反重力汉化包下载完整包、语言更新包还是 Source code？

第一次使用只下载完整包（Antigravity-Windows+Mac.zip）。语言更新包只给已装过完整包的用户更新词条；Source code 是开发源码，不能直接使用。

支持 Antigravity Desktop 2.35 和 Mac 中文版吗？

支持 Windows x64（已在 Antigravity Desktop 2.32.2 至 2.35.1 实测）和 Apple 芯片 Mac，Intel Mac 未验证。只适用于 Google Antigravity Desktop 独立桌面客户端，不是 IDE 扩展。

能让 AI 助手帮我安装吗？

可以。把仓库地址发给 Claude Code、Codex、DeepSeek 等 AI 助手，让它按 AI 助手安装指南 操作。
