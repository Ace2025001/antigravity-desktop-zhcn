Antigravity 汉化包更新日志

汉化包持续补充漏翻词条、跟进客户端新版本。下面是各版本的主要变化，完整记录见 GitHub 发布页。

v2.3.4 （2026-11-10）

  • 修复开启 Antigravity“后台运行”时，启动中文等待 60 秒后提示“客户端未退出”而汉化失败的问题。
  • 客户端运行时给出 60 秒保存时间：手动退出自动继续，按 Y 立即强制关闭，按 N 不强制并一直等待；无操作时先请求正常退出，仍未退出再强制关闭。
  • Windows 客户端关闭时直接从安装目录读取原版界面，客户端更新后也无需先打开客户端。
  • 生成中文界面时实时显示已用时。
  • 精确翻译规则 12,178 条，动态规则 3,079 条。

查看 v2.3.4 完整发布说明

v2.3.3 （2026-11-10）

  • 适配 Antigravity Desktop 2.30.0，修复补丁写入错误位置、重启后仍显示英文的问题。
  • 修复免费方案配额提示半中半英与跨对话搜索新手指引气泡。

查看 v2.3.3 完整发布说明

v2.3.2 （2026-11-07）

  • 精确翻译规则扩充到 12,081 条，动态规则扩充到 3,071 条。
  • 插件的命令、技能、智能体、规则与钩子详情弹窗及 Markdown 正文全量汉化。
  • 新增配额刷新、速率限制与方案升级等动态提示的汉化。
  • 把生硬的“自定义”统一改为“插件”，并润色机翻表达。
