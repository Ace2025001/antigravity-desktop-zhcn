Antigravity 汉化包更新日志

汉化包持续补充漏翻词条、跟进客户端新版本。下面是各版本的主要变化，完整记录见 GitHub 发布页。

v3.0.3 （2026-11-19）

  • 补充内置浏览器清除数据警告、快捷键管理说明、主机名校验、GitHub 身份验证等漏翻。
  • 维护工具：修改词库后可不关闭客户端直接更新中文界面。

v3.0.2 （2026-11-19）

  • 适配客户端 2.33.0：实测点“重启以更新”后自动汉化成功；补上快捷键“终端：全选”、SSH 主机菜单等漏翻。
  • 联网补充翻译更准：快捷键说明、“安装 某插件”、带轮数的对话标题按固定句式生成，插件和服务名保持原名，以前的机翻结果自动被取代。
  • 隐私保护更严格：含文件名、链接、路径或代码的文字一律不联网；设置页里带“终端”“消息”字样的选项不再漏翻。
  • 统一“蜂群”“附带提问”等用语。

v3.0.1 （2026-11-19）

  • 客户端更新后立即跟随汉化（Windows）：在客户端里点“重启以更新”后，等新版本装好就自动重新汉化并打开中文版，过程中有进度窗口，实测约 40 秒；“先问我”模式在更新完成时弹窗询问。
  • 去掉定时计划任务：不再开机检查和每 30 分钟检查，也不常驻后台；v3.0.0 留下的计划任务会自动删除。
  • 首页与说明文档精简，补全汉化覆盖范围说明。

v3.0.0 （2026-11-18）

  • 首次使用会问两项设置：客户端更新后怎么处理（自动汉化 / 先问我 / 不处理）、是否联网补充翻译；新增“汉化设置”入口随时修改。
  • 客户端更新后自动汉化（Windows）：开机时和每 30 分钟检查一次；你正在使用客户端时等你关闭后再汉化，不强制关闭；恢复英文或卸载时删除后台任务。
  • 联网补充翻译可随时开关，关闭后完全不联网；只发送界面文字和对话标题，不发送对话内容、代码和文件。
  • 对话标题只在界面上显示中文，不再修改你的对话记录。
  • 黑框窗口重新设计：按步骤显示进度，用 ✔ / ! / ✘ 标出结果，结束时给出总结；退出客户端时用 1、2 选择。
  • Windows 不再创建“Antigravity自动汉化”快捷方式，已由后台自动汉化取代。
