Antigravity 汉化包更新日志

汉化包持续补充漏翻词条、跟进客户端新版本。下面是各版本的主要变化，完整记录见 GitHub 发布页。

v3.1.3 （2026-11-25）

  • 全端本地命名与原始标识集中保护：在联网与词典双层同时拦截，保护项目文件夹、工作区、文件树、Git 分支、插件/套餐详情大标题、MCP 服务器名与命令行等不被误翻，并自动失效历史误学脏词。
  • 2.35.1 对话标题自动汉化与手动保英文：修复 2.35.1 标题监听脱钩与冷启动竞态；新增手动改名对话永久保英文，并在“汉化设置”中提供“对话标题自动汉化”独立开关。
  • 配额倒计时连写时长与句号修复：支持 1h23m29s 类连写时长准确转为中文并清理多余英文句号。

v3.1.2 （2026-11-25）

  • 修复 Apple 芯片 Mac 启动崩溃：改为整包统一重签并保留权限声明（--deep --preserve-metadata=entitlements），解决 2.35.1 下主程序与内嵌框架因 Team ID 不一致被 dyld 拦截无法打开的问题。
  • 汉化设置与说明页同步：完善“汉化设置”内联网翻译优缺点说明，优化仓库首页下载置顶与新版高清截图排版。

v3.1.1 （2026-11-25）

  • 打开 SSH 主机弹窗全量汉化：修复引导语中英混杂、默认配置标注、按钮及空列表碎片拼接语序问题，补齐加载、连接进度与隐藏主机列表汉化。
  • 智能体状态条消除英文闪烁：在编译期直替 Working、Compacting、压缩耗时与重试倒计时状态标签。
  • 代码块与文件预览切换器汉化：Preview / Raw 及无法预览提示汉化为“预览 / 源码”与“无法预览”。
  • 完成点赞引导窗与搜索优化：交互式“启动中文”完成后置顶显示带仓库直达按钮的小窗（静默自动跟进不打扰）；同步补充常见问答检索词。

v3.1.0 （2026-11-25）

  • 适配客户端 2.35.1 与跨版本组件升级：重写模型徽章、思考程度与步骤进度胶囊的正则注入，解决版本混淆名变化引起的漏翻与机翻；统一思考程度梯队为“低 / 中 / 高 / 超高 / 极高”。
  • 插件页面第三方插件名保留原名：保护 agy-fast、agy-capsule 等开源仓库名及插件卡片标题区，不送入联网翻译，保留与 Git 仓库一致的英文原名，插件描述正常汉化。
  • 消除机翻与补全漏翻：将模型提示 Leaving Soon 规范为“即将下线”（如“此模型将于 11 月 30 日下线”）、Paid Pro 汉化为“付费 Pro”；补齐对话进度胶囊（0/4 步骤、6/6 步骤）及 swarm_pane（蜂群面板）、conversations（对话管理）等内置技能，清理本地误学脏词。
  • 更新接管提示与全流程计时读秒：更新后自动打开客户端时明确提示“关闭更新后自动打开的客户端”；定位客户端、读取界面、关闭等待、应用汉化及拉起启动全程接入实时读秒与耗时总结。

v3.0.10 （2026-11-23）

  • 修复智能体执行过程里文件编辑分组显示成“已编辑 个文件”。
  • 补全模型思考程度与多等级订阅方案的文案。
  • 首页加入三张实机截图，标明已适配客户端 2.34.0。

v3.0.9 （2026-11-22）

  • 模型思考程度及选项规范汉化：将模型选择器二级菜单标题“Thinking effort”规范汉化为“思考程度”，详细说明气泡文案完整汉化；将 Low、Medium、High 等选项及主项徽章统一汉化为“低”、“中”、“高”，彻底消除此前直译为“思考努力”的问题。
  • 订阅方案名称品牌对齐：修复设置中独立出现的“Google AI 专业版”，统一还原为官方规范品牌名“Google AI Pro”。
  • 全面排查与清理自学习词库：清理本地误学的生硬机翻条目，在保护集合中加入品牌词防御。

v3.0.9 （2026-11-19）

  • 自动化与定时任务完整汉化：彻底修复自动化页面列表为空时碎片化 DOM 文本节点导致的 No automations yet 漏翻，统一显示为“暂无自动化”；修复右上角 + New 按钮漏翻为“新建”及其无障碍提示标签。
  • 双保险防护机制：编译期源码替换 + 运行时 DOM 动态拦截双重兜底。

v3.0.7 （2026-11-19）

  • 联网学到的译文只保存在本机文件中，旧版本留在客户端浏览器存储里的副本会自动清除。
  • 首页和网站加入汉化效果截图。

v3.0.1 （2026-11-19）

  • 去掉定时计划任务：不再开机检查和每 30 分钟检查，也不常驻后台；v3.0.0 留下的计划任务会自动删除。
  • 首页与说明文档精简，补全汉化覆盖范围说明。

v3.0.0 （2026-11-18）

  • 首次使用会问两项设置：客户端更新后怎么处理（自动汉化 / 先问我 / 不处理）、是否联网补充翻译；新增“汉化设置”入口随时修改。
  • 客户端更新后自动汉化（Windows）：开机时和每 30 分钟检查一次；你正在使用客户端时等你关闭后再汉化，不强制关闭；恢复英文或卸载时删除后台任务。
  • 联网补充翻译可随时开关，关闭后完全不联网；只发送界面文字和对话标题，不发送对话内容、代码和文件。
  • 对话标题只在界面上显示中文，不再修改你的对话记录。
  • 黑框窗口重新设计：按步骤显示进度，用 ✔ / ! / ✘ 标出结果，结束时给出总结；退出客户端时用 1、2 选择。
  • Windows 不再创建“Antigravity自动汉化”快捷方式，已由后台自动汉化取代。
