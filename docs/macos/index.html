Antigravity Mac 汉化教程

Mac 与 Windows 共用中文语言包；Mac 入口与 arm64 运行环境单独放在“mac启动”目录。

先确认兼容范围

本包内置 Apple 芯片（arm64）运行环境，Intel Mac 未验证。Mac 补充包作者记录的实机环境为 macOS 27.0.1 / Antigravity Desktop 2.29.0 / arm64；合并后的完整流程仍待实机复验。CI 构建通过不能替代真实客户端验收。

首次汉化步骤

  1. 下载安装 Antigravity Desktop 官方客户端，确认英文原版能正常打开。
  2. 下载完整双端包并解压，打开 mac启动 → 启动中文.command。
  3. 自动识别失败或有多个安装时，按提示选择原版 Antigravity.app。
  4. 按引导打开原版，等待首页显示。保存工作，按 ⌘Q 退出，再继续界面采集与汉化流程。
  5. 工具保留官方原版，创建中文应用副本并使用本地签名；完成后按提示启动。

为什么需要准备界面？

Mac 汉化流程需要获取当前官方客户端的界面资源。客户端版本变化后应重新采集，不能套用其他构建的缓存。汉化包内置运行环境，但不替代官方客户端本身。

启动与恢复英文

后续通过“启动中文”或“Antigravity自动汉化”检查并打开中文客户端。需要回到英文时，先保存工作，再运行 mac启动 中的“恢复英文.command”。不要提前删除原版或工具的备份数据。

遇到系统安全提示怎么办？

先核对下载来源与发布页校验信息，保留提示原文供排查，不要关闭 Gatekeeper 或其他系统安全机制。反馈时注明芯片型号、macOS 版本和客户端版本。
