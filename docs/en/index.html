Antigravity Desktop Chinese Language Pack

Switch the Google Antigravity Desktop client to Simplified Chinese (zh-CN). One download for Windows x64 and Apple Silicon Mac, with a bundled runtime that works offline.

Install in three steps

  1. Download the full package (Antigravity-Windows+Mac.zip) and extract the whole archive.
  2. Open win启动 on Windows or mac启动 on Mac.
  3. Run 启动中文 ("Start Chinese") and follow the prompts. To go back, save your work and run 恢复英文 ("Restore English").

What it does

  • Finds your Antigravity Desktop installation automatically, or lets you pick it.
  • Checks the client before changing anything and adapts to new client versions from the running UI.
  • Re-applies Chinese after client or language pack updates via an Antigravity自动汉化 desktop shortcut.
  • Windows: patches the client after making a backup. Mac: keeps the official app and builds a separate, locally signed Chinese copy.
  • If the client is running, you get 60 seconds to save and quit: quitting yourself is detected automatically, Y force-closes now, N waits for you without forcing. With no answer it asks the client to quit, then force-closes it.
  • Never changes proxy, node or TUN settings.

Supported platforms

Antigravity Desktop standalone client on Windows x64 and Apple Silicon macOS, tested on 2.29.0. Intel Macs are not verified. This is not a language pack for the Antigravity IDE extension.

Install with an AI agent

Point Claude Code, Codex, Cursor or another agent at the repository and ask it to follow the AI agent install guide, which covers download, SHA-256 verification, per-platform commands and restore steps.
